# Theory Review

這個資料夾用來記錄 Coding Interview 之外的 CS 基礎與語言理論複習。

## 目標

- 每天約 20～30 分鐘複習一個小主題。
- 不只「看過」，而是要能不看筆記自行解釋。
- 每次複習後記錄理解程度、弱點與下次複習日期。
- 優先補目前實際做題或面試準備中暴露出的缺口。

## 評分方式

| 等級 | 定義 |
|---|---|
| A | 不看筆記能完整解釋，並能回答延伸問題 |
| B | 主概念理解，但部分細節／例子需要提醒 |
| C | 看過且聽得懂，但還不能自己完整解釋 |
| D | 基本概念仍不理解 |

## 複習方式

每個主題盡量包含：

1. 核心概念。
2. 自己能不能口頭解釋。
3. 常見 interview 問題。
4. 一到數個簡短自測題。
5. 本次卡住／答錯的地方。
6. 下次複習日期。

理論複習以「能主動回想」為主，不以閱讀時間當作完成標準。
