## #841 Keys and Rooms

自行完成 C++ queue traversal，不需提示；已訪問才展開，結果正確。Time O(V+E)，Space O(V+E) worst case（queue 可能含重複 entries）；可在入列時就標記 visited 以降低重複。

```cpp
class Solution {
public:
    bool canVisitAllRooms(vector<vector<int>>& rooms) {
        unordered_set<int> visited;
        queue<int> q;
        visited.insert(0);
        for(int i=0;i<rooms[0].size();i++){
            q.push(rooms[0][i]);
        }

        while(q.size()>0){
            int r=q.front();
            q.pop();
            if(visited.find(r)==visited.end()){
                visited.insert(r);
                for(int i=0;i<rooms[r].size();i++){
                    q.push(rooms[r][i]);
                }
            }
        }

        return visited.size()==rooms.size();
    }
};
```

## #416 Partition Equal Subset Sum — 複習

32:55 AC。2026-10-02 已做過（歷史最佳 B）；本次先無法獨立重建，查看舊程式才完成，依獨立性本次 C。演算法與實作正確：target sum/2，反向更新 dp 防止重複使用物件。Time O(nS)，Space O(S)，S=sum/2。保留高優先無參考 Active Recall，不計入新題。

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int s=0;
        for(auto &i:nums){
            s+=i;
        }
        if(s%2==1) return false;
        int m=s/2;

        vector<int> dp(m+1,0);
        dp[0]=1;
        for(int i=0;i<nums.size();i++){
            if(nums[i]>m){
                return false;
            }
            else if(nums[i]==m){
                return true;
            }
            else{
                for(int j=m;j>-1;j--){
                    if(dp[j] && j+nums[i]<m+1){
                        dp[j+nums[i]]=1;
                    }
                }
            }
        }
        return dp[m];
    }
};
```

## #242 Valid Anagram — 複習

06:59 AC，2026-09-11 已做過，僅查 unordered_map API（計數歸零刪 key、查找 key）。核心計數演算法正確，評 A（複習），原最佳 A 不變。Time O(|s|+|t|) average；固定英文字母字元集下額外 O(1) space。char32_t 可用但 char 已足夠。

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        unordered_map<char32_t, int> map;

        for(auto &c:s){
            map[c]++;
        }

        for(auto &c:t){
            if(map.find(c)==map.end() || map[c]<=0){
                return false;
            }
            else{
                map[c]--;
            }
        }

        for(auto& [k,v]: map){
            if(v>0) return false;
        }
        return true;
    }
};
```
