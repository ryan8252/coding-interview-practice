## 今日新增的語言弱點：C++ pointer 初始化

今天在 21 題暴露出一個需要另外複習的 C++ 基礎問題：

```cpp
ListNode* dummy;
ListNode* tail = dummy;
```

這裡的 `dummy` 只是未初始化 pointer，沒有實際的 node 可以操作。

之後需要安排短複習，確認能區分以下兩種寫法：

```cpp
ListNode dummy;
ListNode* tail = &dummy;
```

以及：

```cpp
ListNode* dummy = new ListNode();
ListNode* tail = dummy;
```

重點不是背答案，而是理解：
- 宣告 pointer 不等於建立 object
- `ListNode dummy;` 會建立一個 object
- `&dummy` 取得該 object 的 address
- `new ListNode()` 會建立 node 並回傳 pointer
- 使用 `ptr->member` 前，`ptr` 必須指向有效 object
