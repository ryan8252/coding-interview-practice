## 560
使用 map<int,int>，初始化 m[0]=1；走訪時 prefix 累加，count+=m[prefix-k]，再 m[prefix]++。C++ std::map 版本 O(n log n)，可改 unordered_map 得平均 O(n)。低頻複習目標：無提示辨認負數不適用一般 Sliding Window，重建 prefix-sum frequency 解法。

## 435
起點排序，prevEnd 追蹤保留的結束位置；重疊則 removeCount++ 並讓 prevEnd=min(prevEnd,currentEnd)，否則更新結束位置。O(n log n) time。初始想透過保存 ans 計數，Gemini 說明 C++ vector 不支援 Python 式 intervals[1:] 並建議兩個狀態變數。低頻複習驗證 Greedy 選擇原理。

## 703
C++ 使用 private priority_queue<int, vector<int>, greater<int>> mn 和 int K。建構子放入初始 nums，再 pop 到最多 K 個；add 對不足 K 的情況 push，否則只有新數比 mn.top() 大才替換。Constructor O(n log(n+1)) time，add O(log k)，Space O(k)。C++ Class 語法詢問不算演算法 Hint。已 A，不強制重刷。
