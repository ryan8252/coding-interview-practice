## C++ pointer / object 補充紀錄

今天進一步釐清兩種 dummy node 建立方式：

```cpp
ListNode dummy;
ListNode* tail = &dummy;
```

- `ListNode dummy;` 會真的建立一個 local `ListNode` object。
- `&dummy` 取得該 object 的 address，讓 `tail` 指向它。
- function 結束後 local object 會被銷毀，所以不能回傳 `&dummy`；但回傳 `dummy.next` 指向的原 linked-list node 沒問題。

另一種：

```cpp
ListNode* dummy = new ListNode();
ListNode* tail = dummy;
```

- `new ListNode()` 會建立 dynamic object 並回傳 pointer。
- 正規 C++ 記憶體管理需注意 `delete`，因此單純 dummy node 場景可優先考慮 local object 寫法。

錯誤型態：

```cpp
ListNode* dummy;
```

這只宣告一個 pointer，沒有建立任何 `ListNode` object，不能直接安全使用 `dummy->next`。
