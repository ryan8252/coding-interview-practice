## #740 Delete and Earn — 35:56 AC，C

起初嘗試 Greedy 不成，Gemini 告知「這題可以轉成 House Robber」，此為核心 algorithm reduction 提示；使用者之後自己完成 C++ DP，編碼與狀態轉移正確。

```cpp
class Solution {
public:
    int deleteAndEarn(vector<int>& nums) {
        unordered_map<int,int> m;
        int n=0;
        for(auto &i:nums){
            m[i]++;
            if(i>n) n=i;
        }
        vector<int> dp(n+1,0);
        if(m.find(1)!=m.end()) dp[1]=1*m[1];

        for(int i=2;i<n+1;i++){
            if(m.find(i)!=m.end()){
                dp[i]=max(dp[i-2]+i*m[i],dp[i-1]);
            }
            else dp[i]=dp[i-1];
        }

        return dp[n];
    }
};
```

- Algorithm Design：原 Greedy 不足，House Robber reduction 需 Gemini 重要提示，不能算獨立 Medium。
- Implementation：獲方向後自行建立 frequency map 與 dp，實作正確，無明顯 bug。
- Complexity：令 N=nums.size()，M=max(nums)，平均 O(N+M) time，O(M) space。
- 獨立性：C；即使 AC 也不提升為 A，後續以無參考 reduction 複習。
