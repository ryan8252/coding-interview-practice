## #1091 31:21 TLE 和 Hint 1

使用者自行寫 C++ 八方向 BFS、每層計步數、阻擋起終點、判斷邊界；回報 31:21 TLE，提出從終點再走回來的想法。核心 BFS 選擇和層數邏輯合理，主要效率問題在於 **取出 Queue 時才將 grid[node] 標記 visited**，導致同一格在取出前可被多個鄰居重複入列，大量重複處理。

### 使用者的 31:21 程式

```cpp
class Solution {
public:
    int shortestPathBinaryMatrix(vector<vector<int>>& grid) {
        int n=grid.size();

        if(grid[0][0]==1 || grid[n-1][n-1]==1) return -1;
        const int dx[8]={1,-1,0,0,1,1,-1,-1};
        const int dy[8]={0,0,1,-1,1,-1,1,-1};

        queue<pair<int,int>> q;
        q.push({0,0});
        int cnt=0;
        int arrived=0;
        while(!q.empty()){
            int qsize=q.size();
            for(int j=0;j<qsize;j++){
                auto node=q.front();
                q.pop();
                grid[node.first][node.second]=1;
                // cout<<node.first<<" "<<node.second<<endl;
                if(node.first==n-1 && node.second==n-1){
                    while(!q.empty()) q.pop();
                    arrived=1;
                    break;
                }

                for(int i=0;i<8;i++){
                    int x=node.first+dx[i];
                    int y=node.second+dy[i];

                    if(x>=0 && x<n && y>=0 && y<n){
                        if(grid[x][y]==0){

                            q.push({x,y});
                        }
                    }
                }
            }
            cnt++;
        }
        if(arrived) return cnt;
        else return -1;
    }
};
```
