## 今日重點討論

### 1. Merge Two Sorted Lists：為什麼要用 dummy？

`dummy` 是一個假的頭節點，用來避免特別處理「第一個真正節點」的情況。

```text
dummy -> 1 -> 1 -> 2 -> 3 -> 4
          ^
       真正答案的第一個 node
```

因此最後要：

```python
return dummy.next
```

而不是 `return dummy`。

核心結構：

```python
dummy = ListNode()
tail = dummy

while list1 is not None and list2 is not None:
    if list1.val <= list2.val:
        tail.next = list1
        list1 = list1.next
    else:
        tail.next = list2
        list2 = list2.next
    tail = tail.next

if list1 is not None:
    tail.next = list1
else:
    tail.next = list2

return dummy.next
```

目前需要記住的不是完整程式，而是：Linked List 題常會另外維護 `cur` / `tail`，不一定只改 `head`。

### 2. 448：如何不用 extra space？

因為題目保證：

- 陣列長度是 `n`
- 每個值都在 `1 ~ n`

所以數字 `x` 可以對應到 index `x-1`。

可以直接利用 `nums[x-1]` 的正負號當作「x 是否出現過」的記號。

需要注意：

```python
x = abs(i)
```

因為陣列途中會被改成負數。

而且不能直接每次乘 `-1`，否則重複數字會把負數再翻回正數；應先確認該位置仍為正。

第二次掃描時，仍為正數的位置 `i` 就代表數字 `i+1` 沒有出現。

### 3. 88：為什麼從後面往前合併？

如果從前面開始寫，很容易蓋掉 `nums1` 還沒處理的元素；從尾端開始，後方空間本來就是預留給合併結果，因此可以安全地原地寫入。
