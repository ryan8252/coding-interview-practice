## #875 Koko Eating Bananas — 21:54 AC（新增回報）

本次評價：A（暫定；使用者未明確說是否曾查演算法提示）。自寫 C++ binary search on answer；start=1、end=max pile，使用 ceil_sum 判斷消耗時數，cnt<=h 時記錄可行速度並往左搜尋。Time O(n log M)，Space O(1)，M=max(piles)。使用 long long 累加總時數，程式正確。

```cpp
class Solution {
public:
    long long ceil_sum(vector<int>& piles, int k){
        long long cnt=0;
        for(auto &p:piles){
            cnt+=(p+k-1)/k;
        }
        return cnt;
    }
    int minEatingSpeed(vector<int>& piles, int h) {
        int start=1;
        int end=*max_element(piles.begin(), piles.end());
        int ans=end;
        while(start<=end){
            int mid=start+(end-start)/2;
            long long cnt=ceil_sum(piles,mid);
            if(cnt<=h){
                ans=mid;
                end=mid-1;
            }
            else start=mid+1;
        }
        return ans;
    }
};
```

## #338 Counting Bits — 19:47 AC（再次明確確認）

本次評價：A（暫定；未明確回報是否查演算法提示）。自寫 C++ dp；sub 追蹤不大於 i 的最大 2 的冪，dp[i]=dp[i-sub]+1。Time O(n)，Space O(n) 包含回傳陣列；程式正確。

```cpp
class Solution {
public:
    vector<int> countBits(int n) {
        vector<int> dp(n+1,0);
        int sub=1;
        for(int i=1;i<=n;i++){
            if(sub*2==i){
                sub=i;
            }
            dp[i]=dp[i-sub]+1;
        }
        return dp;
    }
};
```
