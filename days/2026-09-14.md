## Linked List 基礎小練習

今天另外練習了 traversal / count nodes：

```python
class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None


def traversal(head):
    c = 0
    while head is not None:
        c += 1
        head = head.next
    return c
```

原本漏掉了：

```python
head = head.next
```

如果沒有這一行，只要 `head` 不是 `None`，while loop 就會一直停在同一個 node，形成 infinite loop。

`ListNode.__init__` 今天是照範例抄的，目前重點不是死背 class 定義，而是先熟悉：

- `node.val`：目前 node 的值
- `node.next`：下一個 node
- `None`：Linked List 結尾
- traversal 的基本骨架：`cur = cur.next`

## 141. Linked List Cycle 討論重點

### 1. 用 Set 記錄走過的 node

Set 裡要存的是 **node 本身**，不是 `node.val`。

即使兩個 node 的值相同：

```text
A(val=5) -> B(val=5)
```

A 和 B 仍然是不同的 node，因此可以同時存在 Set 中。

概念：

```python
seen = set()
cur = head

while cur is not None:
    if cur in seen:
        return True
    seen.add(cur)
    cur = cur.next

return False
```

複雜度：

- Time: O(n)
- Space: O(n)

### 2. Floyd Slow / Fast Pointer

使用兩個 pointer：

- `slow` 每次走 1 步
- `fast` 每次走 2 步

如果沒有 cycle，`fast` 最後會走到 `None`。

如果有 cycle，兩個 pointer 進入環後，fast 每輪會比 slow 多走一步，因此最後一定會追上 slow。

```python
slow = head
fast = head

while fast is not None and fast.next is not None:
    slow = slow.next
    fast = fast.next.next

    if slow == fast:
        return True

return False
```

複雜度：

- Time: O(n)
- Space: O(1)

### 3. 今天自己的「走超過 10,000 步」方法

本題明確限制 node 數量，因此如果走超過最大可能的不同 node 數仍然沒有遇到 `None`，依 pigeonhole principle，一定重複經過某個 node，也就是存在 cycle。

所以這個方法在本題 constraints 下是合法的，不是亂猜。

但缺點是它依賴「已知最大節點數」。如果 Linked List 長度沒有上限，就不能使用固定 counter。

另外實際速度也不一定比 Floyd 快：

- 對沒有 cycle 的 list，兩者都會走到尾端。
- 如果 cycle 很小，Floyd 可能很快相遇；固定 counter 方法仍可能走很多步才停。
- 兩者 Big-O 都可以是 O(n)，但 constant factor 與實際停止時間不同。
